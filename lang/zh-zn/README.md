# ARC Minecraft 社群伺服器整合包

## 專案概覽
本整合包由 ARC 社群維護，旨在簡化伺服器存取流程、統一版本管理，並提供平衡的遊戲體驗。

## 入門指南
獲取檔案：請從 發佈 (Releases) 頁面下載最新的穩定版本。

安裝設定：使用相容的 Minecraft 啟動器匯入整合包檔案。

啟動執行：啟動前請確保硬體資源分配符合當前版本的建議配備。

## 為確保客戶端穩定性與伺服器相容性，每次重大更新時均建議進行全新安裝。

資料備份：在升級前，請手動備份您的個人設定檔與本地數據。

資料還原：安裝新版本後，將備份的數據移至新的實例目錄下。

避免衝突：請避免直接遷移全域設定資料夾，以確保新版本的伺服器端優化能正確生效。

## 技術支援與貢獻
若需技術支援、回報程式錯誤或提出功能建議，請利用本倉庫的 議題 (Issues) 追蹤功能，或透過官方社群管道聯繫管理員。
