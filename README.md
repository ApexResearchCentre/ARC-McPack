# ARC Minecraft Community Server 

[中文](https://github.com/ApexResearchCentre/ARC-McPack/tree/main/lang/zh-zn#readme)

## Overview
This modpack is maintained by the ARC Community to streamline server access, manage version control, and deliver a balanced gameplay experience.

## Getting Started
Acquisition: Download the latest stable build from the Releases section.

Setup: Import the package using a compatible Minecraft launcher.

Execution: Ensure your hardware resource allocation meets the recommended requirements for the current version before launching.

## Version Migration
To maintain client stability and server compatibility, a clean installation is required for every major update.

Preservation: Before upgrading, manually back up your personal configuration files and local data.

Restoration: After installing the new version, restore your backed-up data to the new instance directory.

Conflict Prevention: Avoid migrating global configuration folders to ensure the latest server-side optimisations are applied correctly.

## Support & Contributions
For technical assistance, bug reporting, or feature requests, please utilise the Issues tracker within this repository or contact the administration through official community channels.
